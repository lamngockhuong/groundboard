# Signup requirements

Copied from the client brief "Shop signup v2" on 2026-11-19.

## Screens

1. Sign up: the visitor creates an account.
2. Verify email: the visitor enters the six-digit code sent to their address.
3. Welcome: the new customer is greeted and can start shopping.

## Sign up

The Sign up screen follows the client mockup `design/signup-mockup.png`.

- The Display name field stores the name shown on the account.
- The Email field stores the address the code is sent to.
- The Password field stores a password of at least 12 characters.
- The Create account button submits the form and opens the Verify email screen.

## Verify email

- The Code field accepts the six-digit code.
- The Verify button checks the code and opens the Welcome screen when it matches.
